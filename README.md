## Selected projects

### 2048

A browser game with one-move undo, saved progress, multiple board sizes, and keyboard, touch, and mouse controls. Game rules live separately from the interface, with Redux Toolkit managing the board and browser storage preserving progress.

**React · TypeScript · Redux Toolkit · Vite**

[Play](https://preact-2048-game.vercel.app/) · [Code and implementation notes](https://github.com/VladislavDegtyarenko/preact-2048-game)

### Weather App

A dashboard for current conditions and forecasts across saved cities. It combines city search, readable routes, forecast charts, and browser persistence, with tests for routing and city-list state.

**React · TypeScript · Redux Toolkit · Material UI · Chart.js**

[Try the demo](https://vd-react-weather-app.vercel.app/) · [Code and setup](https://github.com/VladislavDegtyarenko/react-weather-app)
